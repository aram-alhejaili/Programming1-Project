# Programming 1 Project – Password Services (Java)

## 📌 Project Overview
This project was developed as part of the Programming 1 course.  
It is a console-based Java application that provides simple password services including generating random passwords and evaluating password strength.

## 🎯 Project Purpose
The purpose of this project is to practice fundamental Java programming skills through a practical application.  
It focuses on generating secure passwords, evaluating password strength, and improving logical problem-solving using basic programming concepts.

## ✅ Features
- Generate three random passwords based on a user-defined length
- Evaluate the strength of a user-entered password
- Generate passwords and display their strength scores
- Menu-driven console interface for user interaction

## 🔍 Password Strength Criteria
Password strength is evaluated based on:
- Presence of uppercase letters
- Presence of lowercase letters
- Inclusion of digits
- Inclusion of special characters
- Password length (at least 8 characters)

## 🛠 Technologies Used
- Java
- Console input/output (Scanner)
- Basic programming concepts (loops, conditions, methods)

## ▶️ How to Run
1. Compile the program
2. Run the main class:
   `PasswordServices1`
3. Choose a service from the menu or exit the program
